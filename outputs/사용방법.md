# MewFit 사용 방법 (How to Use MewFit)

## 0. 무엇인가요?

**MewFit**은 Mike Mew의 orthotropics 프로토콜과 PubMed에 등재된 근기능치료(Orofacial Myofunctional Therapy, OMT) 연구를 바탕으로 만든 **PWA 웹앱**입니다. 아이폰 홈 화면에 추가하면 일반 앱처럼 작동하며, 6개의 뮤잉/근기능 운동을 단계별 애니메이션·타이머·진행 기록과 함께 안내합니다.

포함 파일:
- `index.html` — 앱 본체
- `manifest.webmanifest` — PWA 설치 매니페스트
- `sw.js` — 서비스 워커 (오프라인 + 푸시 알림 처리)
- `icon-192.png`, `icon-512.png` — 홈 화면 아이콘
- `MewFit_알림.ics` — 알림 백업용 캘린더 파일
- `연구요약.md` — 의학적 근거 요약
- `기획서.md` — 향후 네이티브 앱 개발자용 기획서

---

## 1. 빠르게 시작하기 (로컬 테스트)

**Mac/PC에서 미리 확인하기:**

```bash
# outputs 폴더에서 이 명령을 실행
python3 -m http.server 8080
# 또는
npx serve .
```

브라우저에서 `http://localhost:8080` 으로 접속하세요.

> ⚠️ PWA 설치/푸시 알림은 **HTTPS** 환경에서만 작동합니다. 로컬 테스트는 OK이지만 아이폰에서 사용하려면 HTTPS 호스팅이 필요합니다.

---

## 2. 인터넷에 올리기 (HTTPS 호스팅)

가장 쉬운 방법 3가지:

### A. GitHub Pages (무료, 추천)
1. GitHub 계정에 새 리포지토리(`mewfit` 등) 생성 → Public
2. `outputs/` 폴더의 모든 파일 업로드 (드래그&드롭)
3. 리포 Settings → Pages → Source: `main` branch, root → Save
4. 1–2분 후 `https://[username].github.io/mewfit/` 주소 활성화
5. **이 주소를 아이폰 Safari로 열기**

### B. Netlify (무료)
1. https://app.netlify.com → Sites → "Add new" → "Deploy manually"
2. `outputs/` 폴더를 통째로 드래그
3. 부여된 `https://*.netlify.app` 주소 사용

### C. Cloudflare Pages (무료, 가장 빠름)
1. https://pages.cloudflare.com → "Create a project" → Direct Upload
2. `outputs/` 폴더 업로드
3. `https://*.pages.dev` 주소 사용

---

## 3. 아이폰에 설치하기

1. **Safari로** 위에서 받은 HTTPS 주소를 엽니다 (Chrome 안 됨, 반드시 Safari).
2. 화면 하단(또는 상단) 가운데의 **공유 버튼** 📤 을 누릅니다.
3. 스크롤하여 **"홈 화면에 추가"** (Add to Home Screen) 선택.
4. 이름을 "MewFit"으로 두고 → "추가".
5. 홈 화면의 **MewFit 아이콘**으로 실행합니다 (반드시 홈 화면 아이콘으로! Safari 탭으로 열면 알림이 안 갑니다).
6. 첫 실행 시 **설정 → 알림 사용** 토글을 켜고 권한을 허용해주세요.

---

## 4. 알림이 작동하지 않을 때 — 백업 방법

iOS의 PWA 푸시는 백그라운드 정확도가 완벽하지 않습니다. 더 확실한 방법으로 **`MewFit_알림.ics` 파일**을 사용하세요:

1. `MewFit_알림.ics` 파일을 자기 자신에게 메일/iCloud Drive로 전송
2. 아이폰에서 파일을 탭 → "캘린더에 추가" 선택
3. 매일 6번(08:00 / 11:00 / 14:00 / 17:00 / 20:00 / 22:30) 자동 알림
4. 알림이 울리면 **"MewFit 열기"** 단축어 또는 홈 화면 아이콘으로 진입해서 운동 → 기록

> 💡 시간을 바꾸고 싶다면 캘린더 앱에서 직접 일정을 편집하면 됩니다.

## 5. 일상 사용 흐름

| 단계 | 화면 | 동작 |
|---|---|---|
| 1 | 알림이 울림 | 푸시 또는 캘린더 |
| 2 | MewFit 열기 | 홈 화면에서 |
| 3 | "오늘의 운동" 카드 | 다음 슬롯의 운동 탭 |
| 4 | 운동 화면 | 애니메이션 + 단계 확인 → "시작" |
| 5 | 타이머 진행 | 단계별 자동 진행 |
| 6 | 완료 모달 | 자동 기록됨, "확인" |
| 7 | 홈/기록 화면 | 연속 일수·달력 확인 |

각 시간대는 6개 운동 중 하나가 배정되어 자동 순환됩니다 (정자세 → 4S 삼킴 → 혀 클릭 → 입술 봉합 → 혀 흡착 → 코호흡).

---

## 6. 6개 운동 빠른 참조 카드

| 운동 | 시간 | 핵심 |
|---|---|---|
| ① **정자세** | ~5.5분 | 혀 전체를 입천장에 흡착, 10회 |
| ② **4S 삼킴** | ~2분 | Spot–Salivate–Squeeze–Swallow, 6회 |
| ③ **혀 끝 클릭** | ~1분 | 후방은 유지, 끝만 딸깍, 10×3세트 |
| ④ **입술 봉합** | ~4.5분 | 턱 이완 + 입술만 다물기 15초×10회 |
| ⑤ **혀 흡착 유지** | ~4분 | 진공 흡착 20초×8회 |
| ⑥ **코호흡 4-2-4** | ~2분 | 코로 4초 들이마심·2초 멈춤·4초 내쉼, 10주기 |

## 7. 안전 주의사항

- 시작 전 **치과 전문의 진료** 권장 (오픈바이트 유형, 설소대 유무 확인).
- TMJ 통증 동반 시 **하드 뮤잉 금지** — 부드러운 압력만.
- 턱·관자놀이 통증, 두통 발생 시 즉시 중단하고 전문의 상담.
- **꾸준함이 강도보다 중요** — 짧은 시간 매일 > 가끔 길게.
- 만 18세 미만은 보호자/교정의와 상의.

---

## 8. 데이터 관리

- **내보내기**: 설정 → "데이터 내보내기" → JSON 파일 다운로드
- **초기화**: 설정 → "기록 초기화" (확인 한 번 더)
- 기록은 브라우저 LocalStorage에 저장 → 같은 도메인·같은 브라우저에서만 유지
- 폰 변경 시 JSON 내보내기 후 새 폰에 수동으로 복원 (앱 향후 버전에 import 추가 예정)

---

## 9. 향후 네이티브 앱(앱스토어)으로 발전시키려면?

`기획서.md`를 참고하여 SwiftUI 또는 React Native 개발자에게 의뢰하세요. 본 PWA를 그대로 WKWebView로 감싸는 방법도 있지만 (가장 빠름), 정식 앱스토어 등록 시에는 다음이 필요합니다:

- Apple Developer Program 가입 ($99/년)
- 푸시 알림용 APNs 인증서 또는 로컬 알림 구현
- App Review (의료 관련은 약간 더 까다로움 — "교육용·자가관리"로 명시)

---

## 10. 출처 및 의학적 면책

이 앱은 **교육 목적**이며 진단·치료를 대체하지 않습니다. 자세한 학술 출처는 `연구요약.md`를 참고하세요.

대표 근거:
- Smithpeter J, Covell DA. *AJODO* 2010 — OMT 병행 시 AOB 재발 0.5mm vs 비병행 3.4mm
- AAOM/IAOM 표준 OMT 프로토콜
- Mike Mew Orthotropics 공식 가이드

문제·제안은 앱의 "정보" 화면 참조.
