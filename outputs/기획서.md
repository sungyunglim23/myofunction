# MewFit 네이티브 앱 기획서 (App Spec for Native Development)

> 향후 SwiftUI/React Native로 정식 앱스토어 발매를 진행할 경우 개발자에게 전달할 기획 문서.
> 본 문서는 PWA(`index.html`)에 구현된 모든 기능을 1:1로 재현하는 것을 기본으로 합니다.

---

## 1. 제품 개요

- **이름**: MewFit
- **카테고리**: Health & Fitness / Medical Self-Care
- **타깃**: 오픈바이트(anterior open bite)·TMJ 자가관리에 관심 있는 한국·영어권 사용자
- **포지셔닝**: Mike Mew의 orthotropics 프로토콜과 PubMed 등재 OMT 연구를 결합한 **단계별 자기 훈련 코치**
- **플랫폼**: iOS 16.0+ (1차), Android 추후

## 2. 핵심 기능 (Core Features)

| # | 기능 | 우선순위 |
|---|---|---|
| 1 | 6개 운동의 단계별 애니메이션·타이머 안내 | P0 |
| 2 | 하루 5–6회 푸시 알림 (시간 사용자 설정) | P0 |
| 3 | 운동 완료 기록 + 연속(streak) 트래킹 | P0 |
| 4 | 30일 캘린더 히트맵 + 운동별 통계 | P0 |
| 5 | 한국어/영어 i18n | P0 |
| 6 | 데이터 내보내기/가져오기(JSON) | P1 |
| 7 | iCloud 동기화 (멀티 디바이스) | P2 |
| 8 | Apple Health 연동 (마음챙김 분 기록) | P2 |
| 9 | 치과 전문의 공유 리포트(PDF) | P2 |
| 10 | 소셜 챌린지 / 친구 비교 | P3 |

## 3. 화면 구조

### 3.1 IA (Information Architecture)
```
Tab Bar
├── Home (오늘의 운동 + 통계 헤더)
├── Train (6개 운동 그리드 + 운동 상세)
├── History (캘린더 + 운동별 통계)
└── Settings (알림, 데이터, 정보)
```

### 3.2 화면 흐름
- **Onboarding** (첫 실행)
  1. 환영 슬라이드 3장 (PWA에 없음, 네이티브에서 신규)
  2. 알림 권한 요청
  3. 알림 시간 설정 (기본값 6개 미리 채움)
  4. 의학적 면책 동의 ✅

- **Home**
  - 헤더 통계 3개: 연속 일수 / 오늘 진행률 / 누적 세션
  - 오늘의 운동 카드 (시간 슬롯 6개, 각자 다른 운동 자동 배정)
  - 운동 그리드 (6개)
  - 권장 빈도 설명 카드

- **Train**
  - 운동 상세: 애니메이션 + 단계 리스트 + 타이머
  - 시작 → 단계 자동 진행 → 라운드 반복 → 완료 모달 → 기록 자동 저장

- **History**
  - 6주(42칸) 히트맵 캘린더 (오늘 강조, 진하기 = 세션 수)
  - 주간 평균 + 목표 달성률
  - 운동별 누적 막대 그래프

- **Settings**
  - 알림 토글, 시간 추가/편집/삭제(롱프레스)
  - 언어 토글 (한 ↔ EN)
  - 데이터 내보내기 / 초기화
  - 정보 (의학적 출처 링크)

## 4. 운동 데이터 (Exercises)

| ID | 한국어 | 영어 | 단계 | 라운드 | 휴식 | 타깃 |
|---|---|---|---|---|---|---|
| `spot` | 정자세 | Tongue Spot Posture | 4단계 (6+6+8+10초) | 10 | 3초 | 혀 휴식 위치 |
| `4s` | 4S 삼킴 | 4S Swallow | 4단계 (4+5+4+5초) | 6 | 4초 | 연하 패턴 |
| `click` | 혀 끝 클릭 | Tongue Click | 4단계 (5+3+2+12초) | 3 | 5초 | 혀 끝 미세 조절 |
| `lipseal` | 입술 봉합 | Lip Seal Hold | 3단계 (4+3+15초) | 10 | 5초 | 입술 무력증 |
| `suction` | 혀 흡착 유지 | Suction Hold | 3단계 (4+3+20초) | 8 | 5초 | 구개 흡착력 |
| `breathe` | 코호흡 4-2-4 | Nasal Breathing | 3단계 (4+2+4초) | 10 | 0초 | 코호흡 습관 |

각 운동은 PWA의 `EXERCISES` 배열에서 그대로 가져옵니다. 단계 텍스트는 `(ko, en, duration)` 튜플로 정의됨.

## 6. 기술 스택 추천

### iOS Native
- **Swift 5.9 + SwiftUI**
- `UserNotifications` 프레임워크 (로컬 스케줄링)
- `SwiftData` 또는 Core Data (히스토리)
- `Charts` 프레임워크 (히트맵 직접 구현 또는 `SwiftUICalendarHeatmap`)
- 애니메이션: `withAnimation` + `.matchedGeometryEffect` 또는 Lottie/Rive
- 위젯: `WidgetKit` (오늘의 진행률 위젯, P1)
- Live Activity: 운동 진행 중 (P2)

### React Native 대안
- React Native + Expo
- `expo-notifications` 로컬 알림
- `react-native-mmkv` 또는 `expo-sqlite`
- Reanimated 3로 SVG 애니메이션 재현

### 가장 빠른 길
- **WKWebView 래퍼**: 본 PWA를 그대로 iOS 앱 안에서 표시 + 네이티브 알림만 새로 구현
- 1–2주 내 앱스토어 제출 가능, 단 App Review에서 "충분한 네이티브 통합" 요구 가능성

## 7. 비기능 요구사항

- **오프라인 동작**: 100% 오프라인. 네트워크 없이 모든 운동 가능.
- **데이터 위치**: 단말 내 영구 저장. 클라우드는 옵트인.
- **개인정보**: 외부 서버 전송 0. (분석 추가 시 `On-Device only` 또는 옵트인)
- **접근성**: VoiceOver, Dynamic Type, Reduce Motion (애니메이션 끄기) 지원.
- **국제화**: 1차 ko·en, 추후 ja·zh 추가 가능.

## 8. 의학적 컴플라이언스

- **App Store Medical Disclaimer**: "교육용 정보, 진단·치료 대체 아님" 명시.
- **Korea KFDA**: 본 앱은 '의료기기'가 아닌 **건강관리 앱**으로 분류 — 적응증·치료효과 주장 금지, 단어 신중히 선택.
- 모든 의학 콘텐츠 출처 표기 의무 (PWA 설정 화면 정보 카드 그대로 유지).
